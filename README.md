# Bugün Ne Giysem?

Bugün Ne Giysem? , gardıroptaki parçaları kullanarak günlük bir kıyafet kombini oluşturmayı kolaylaştıran bir web uygulamasıdır. Uygulama rastgele bir kombin önerebilir veya kombin seçimini kullanıcıya bırakır.

## Özellikler

- Üst giyim, alt giyim ve ayakkabı kategorilerinden ürün seçme
- Seçilen parçaları kombin önizlemesinde görme
- Kendi seçmek istemeyenler için tek tıklamayla rastgele kombin oluşturma

## Kullanılan teknolojiler

- HTML
- CSS
- JavaScript

## Çalıştırma

Projeyi indirin veya bilgisayarınıza kopyalayın. `index.html` dosyasını bir tarayıcıda açmanız yeterlidir; ek bir kurulum gerekmez.

## Proje dosyaları

- `index.html`: Sayfa içeriği ve uygulama ekranları
- `style.css`: Görünüm ve farklı ekran boyutlarına uyum
- `script.js`: Rastgele kombin ve ürün seçme işlevleri
- `ust1.jpeg`–`ust7.jpeg`: Üst giyim görselleri
- `alt1.jpeg`–`alt7.jpeg`: Alt giyim görselleri
- `ayakkabi1.jpeg`–`ayakkabi7.jpeg`: Ayakkabı görselleri
